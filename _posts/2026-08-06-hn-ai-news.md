  - title: Stateless MCP has recaptured my interest
    link: https://simonwillison.net/2026/Jul/31/stateless-mcp/
    domain: simonwillison.net
    summary: MCP's stateless overhaul makes servers simple HTTP endpoints, reigniting developer interest after
      session complexity stalled adoption
    points: 312
    hn_url: https://news.ycombinator.com/item?id=49131438
    comments: 0
    time: Aug 05, 05:22 UTC
    content_bullets:
    - The MCP (Model Context Protocol) 2026-07-28 spec eliminates mandatory session management entirely — the initialize
      handshake, Mcp-Session-Id header, and sticky routing requirements are all gone; any round-robin load-balanced
      HTTP endpoint now qualifies as an MCP server.
    - State is made explicit rather than hidden — instead of opaque server-side sessions, models thread identifiers
      between tool calls, keeping state visible and composable within the model's own reasoning context.
    - A new server/discover method lets clients fetch server capabilities on-demand per request, replacing the stateful
      handshake and enabling genuine stateless retry logic.
    - Willison released two new tools enabled by the simpler spec — mcp-explorer (inspect any MCP server's capabilities)
      and datasette-mcp (an MCP interface for his Datasette data platform), both trivially deployable on serverless.
    - Three features enter deprecation — Roots, Sampling, and Logging — further slimming what an MCP server must
      implement; the result is a much smaller compliance surface for new integrations.
    discussion_bullets:
    - Commenters widely echoed Willison's earlier frustration — session-management requirements were the single
      biggest barrier to building lightweight MCP integrations, and stateless HTTP feels far more natural to web
      developers.
    - A recurring debate questioned whether stateless design trades simplicity for power in genuinely long-running
      agent workflows, with some arguing that explicit state threading puts cognitive load on the model rather than
      the infrastructure.
    - Willison's mcp-explorer and datasette-mcp attracted attention as proof-of-concept examples, spurring discussion
      about a coming wave of simple MCP servers now that serverless deployment is a first-class path.
