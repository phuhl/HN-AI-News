        link: "https://thehackernews.com/2026/08/openai-anthropic-google-api-flaw-let.html"
        domain: "thehackernews.com"
        summary: "Researchers from ELLIS Tübingen and MPI revealed that a single global encryption key protects chain-of-thought reasoning across OpenAI, Anthropic, and Google APIs — allowing weaker models to decode stronger models' private reasoning."
        points: 876
        hn_url: "https://news.ycombinator.com/item?id=49257876"
        comments: 614
        time: "Aug 17, 09:15 UTC"
        content_bullets:
          - "The attack captures an encrypted reasoning envelope from a frontier model (e.g. Claude Opus 4.8) and replays it into a smaller sibling model (e.g. Claude Haiku 4.5) that transcribes the internal thoughts in plain text."
          - "Researchers scraped 6,708 public agent-trajectory logs from GitHub and Hugging Face, decoded 315,320 reasoning blocks, and recovered 182 real credentials — API keys, passwords, and access tokens — from genuine user sessions."
          - "All three providers used a single global key; following responsible disclosure, server-side mitigations were deployed and the original replay proof-of-concept no longer works on current builds."
          - "The root cause is architectural: encrypted chain-of-thought was designed to protect the provider's proprietary reasoning from competitors, not to protect user data — so user data leaking through it was an unconsidered threat model."
        discussion_bullets:
          - "HN security researchers noted that 'encrypted CoT' was always more about IP protection than privacy, and this exposure shows what happens when those two goals are confused."
          - "A major thread debated whether agent trajectory logs should ever be public — most frameworks log these by default for debugging, but they can contain sensitive context from the original session."
          - "Several commenters argued that 'server-side mitigations' are insufficient; the underlying architecture should use per-session keys, not a global one, to bound the blast radius of any future discovery."
